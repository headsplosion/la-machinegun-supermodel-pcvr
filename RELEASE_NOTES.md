Windows build of Supermodel with the OpenXR VR mode, set up for **L.A. Machineguns**.

**Download** `SupermodelVR-windows.zip` below and unzip it. Put your own `lamachin.zip` ROM set in the `ROMs` folder. Connect the headset, with Virtual Desktop, Quest Link or SteamVR as the active OpenXR runtime, and run `Play LA Machineguns VR.bat`. Full instructions are in `README-VR.txt` inside the zip and in the README. No ROMs or other game files are included.

## What's new in v0.4.0

### Screen glow in cinema mode
- New option: **Comfort › Screen glow** (Off / Subtle / Strong; `VRCinemaGlow`, Subtle by default).
- The colours at the edges of the picture light up the dark room around the cinema screen, like the ambient light around a TV or an arcade screen. Explosions, skies and neon all spill onto the wall.

### Sharper options menu
- **Bold typeface.** The menu now uses a bold version of Michroma, which reads more easily in the headset.
- **No more shimmer.** The menu is drawn at twice the resolution and smoothly scaled, so text and edges stay steady when you move your head.

### Also included since v0.3.0
Everything from v0.3.0 is still here: the two-gun akimbo mode, the in-headset options menu, cinema mode with 3D depth, the comfort vignette, the hidden player 2 prompt, and full-view hit static. See the README for the full list of features, controls and options.
